# MathorCup 大数据竞赛适配器

- 论文型交付：初赛 3 问、复赛 2 问，论文 + result 结果文件（CSV/XLSX/TXT，模板固定，不改格式与 ID 对应）；
- 封面写明队伍编号、赛道、题目；摘要按问题写方法、关键数值与结论，关键词 3--6 个；
- 赛道 A 多为当热模态（CV 图像/时空轨迹），赛道 B 多为企业表格（预测 + 优化）；以当届题面为准；
- 方法以机器学习为主线：随机森林/XGBoost/LightGBM/CatBoost、Stacking 融合、SMOTE/代价敏感；时序用 ARIMA/Prophet/LSTM；CV 用 YOLO/预训练 CNN；优化用 MILP/NSGA-II/MOPSO；
- 每问配技术路线流程图，做系统多模型对比与多指标评估、残差/学习曲线诊断，并给出一个明确创新点；
- 正文不堆代码，完整代码与结果明细放附录；图表、公式、参考文献统一；
- 不套用经典 AHP/TOPSIS 或固定模板句，方法与写作以本题证据为核心；当届页数、匿名、AI 披露等以官方通知为准。
