# 独立科学复算扩展：时序、统计推断、随机仿真与连续凸优化（v2.7）

本模块**面向未知赛题的可验证任务类型**，不预设 MathorCup 今年的模型，也不把往届论文算法当正确答案。先依据当届题面和数学假设判断是否适用参考计算器，再把真实输入和主程序结果作为独立检查对象。

## 独立参考计算器

```bash
python skills/big-data-competition-skill/tools/extended_oracles.py --case /path/to/actual_check.json
```

| task | 输入数据/声明 | 重新计算 | 必要的证据边界 |
|---|---|---|---|
| `rolling_forecast` | 时间整数索引、训练/验证边界、预留 gap、每折真实值与预测值、声称指标 | 每折 MAE、全部原子预测的 MAE/RMSE；同序列训练窗推进和验证窗不重叠 | 只能核查**自报**时间边界和误差；特征工程实际用到的时间仍需查代码 |
| `paired_signflip` | 合法配对观测、配对主键、sign-exchangeability 的零假设、预声明 alpha、声称 p 值 | 最多 16 对数据的 (2^n) 个符号翻转，得双侧精确置换 p 值 | **只有在符号交换性/配对独立等假设成立时才有效**；不能推断因果或忽视多重比较 |
| `bernoulli_mc` | 真实 0/1 原子输出、iid Bernoulli 抽样声明、预声明精度、置信水平 | 比例、Wilson 区间及是否满足指定区间半宽 | iid 只由使用者声明，脚本不能证明。相关样本、复杂抽样、importance sampling 不适用 |
| `separable_convex_quadratic` | 对角严格正二次目标、线性系数、独立盒约束和候选解 | 逐维闭式解 (x_i^*=clip(-b_i/(2a_i),l_i,u_i))、目标值、可行性、实际目标差距 | **仅**适用于可分离严格凸二次最小化；非线性耦合、混合整数或一般非凸问题不适用 |

四个分支均拒绝明显不符合输入契约的数值，例如 NaN、非法报告、缺失结构和越过适用范围的输入。参考计算器不训练模型，不能证明真实数据合法、预测可泛化、观察具有因果性。

## 为什么强调“逐条数据、独立计算”

模型和正文都记录同一错误数字，只比较两个文件不会发现；独立计算则从更基础的**原子标签、预测、观测或数学目标**重新出发。真正的独立性还应要求检查人员复核原题单位、变量定义和标签的预测时点。若主模型与参考器都接受了相同的错误数学定义，双方可能一致而仍答错原题。

时序评价应先冻结数据时间结构、预测 horizon 和 embargo/gap 的实际含义；不可拿整理后的一组误差反推“没有泄漏”。当数据受群组、地理位置、事件、滚动窗口等因素影响时，另行审核实体/空间泄漏、样本重复和置信区间假设。

对统计检验，要区分**数值上精确的随机化分布**与**科学上可靠的研究设计**：前者可以枚举，后者需要审查配对、交换性、实验设计、预注册和多重检验。显著性不是效应量，也不是因果证明。论文应报告实际均值差、检验假设、p 值与局限，而不是只写“显著优于”。

随机仿真应至少保留原始抽样、抽样算法/独立随机流、预设精度标准、模拟过程模型与真实问题之间的关系。工具的 `precision_met` 只表示**在 iid Bernoulli 假设下** Wilson 半宽达标，不意味着模拟模型真实。

优化应明白区分：**对这个数学模型的解析最优**、**小规模子实例的精确最优**、以及**整个真实资源调度赛题的实际最优性**。本工具只支持第一类中特定的严格凸、盒约束可分模型；不代表整个竞赛优化算法已经被证明。

## 用于模型与论文终审

1. 确定当届问题的数学契约，记录每个结论的可证伪标准与相关领域假设。
2. 使用适用的参考器核对真实原子结果；**先验定义成功规则**，禁止为了通过而篡改检验阈值。
3. 另做反例测试、敏感性分析、统计可靠性复核及模型特有的边界检验。
4. 正式论文采用“题意—模型依据—求解—独立核对—不确定性—有界结论”的顺序；与原始指标文件的三方比对使用 `paper_evidence_gate.py --require-metric-source`。
5. 对不适用上述四类计算器的题目，**设计题型特有的正确性 oracle**，而不是跳过独立审核。

参见 [v2.6 独立复算](independent-recomputation.md)、[模型与结论正确性](solution-validity.md)、[稳定性与不确定性](stability-and-uncertainty.md)、[论文论证](paper-argumentation.md)。

## 测试证据范围

`tests/test_bigdata_extended_oracles.py` 内含 28 个合成手算/不变量/边界/故障测试；这些都是**工具的测试**，不是 MathorCup 历史赛题模型表现。对任意实际赛题，仍需用真正获授权且没有评价污染的数据作独立检验。
