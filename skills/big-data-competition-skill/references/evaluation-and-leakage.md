# Evaluation and Leakage

验证必须复现比赛预测时真正可获得的信息。

重点检查：
- 时间顺序和未来信息
- 实体重叠
- 重复与近重复样本
- 跨表连接泄漏
- split 前全量预处理
- 标签生成过程
- 外部数据的时间可得性
- 测试集反向参与调参

红旗：
- 特征时间晚于目标事件
- 同一实体跨越不应重叠的验证集
- 全数据标准化或编码后再切分
- 测试集参与特征选择
- 极小改动导致异常大的分数跃升
- 无合理解释的近乎完美模型

稳健性测试应选择最便宜但能回答问题的方法，例如备用切分、重复随机种子、时间窗口变化、子群分析、Bootstrap 或外部验证。
## 独立审核与条件验证

数据拆分正确也不能自动证明模型公式/数值计算正确。要求独立 Reviewer 验证一次关键数值或求解器约束，讨论度量尺度、边界案例和可能的错误结论。参考 [完整解答质量审核](solution-validity.md)；稳定性另按 [扰动与不确定性](stability-and-uncertainty.md) 设计，不能用单次分数声称稳健。
