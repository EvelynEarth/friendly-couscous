# Result Analysis

结果分析负责回答结果说明什么和结果是否稳健，不负责暗改主求解逻辑。

每项深化分析绑定一个 target claim，并记录 support、modify、reject。

## Preferred analyses

- baseline comparison
- subgroup analysis
- residual or error diagnosis
- sensitivity
- ablation
- uncertainty
- temporal or spatial stability
- failure cases

reject 核心结论时必须回退到模型、实验或验证阶段。
