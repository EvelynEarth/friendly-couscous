# Final Review

终审从评委视角检查四层：

1. 题目层：是否完整回答赛题。
2. 方法层：方法是否与任务和数据结构匹配。
3. 证据层：结果是否经过合理验证，是否存在泄漏或过度解释。
4. 论文层：图表、数字、引用、术语和结论是否一致。

高风险问题包括：无 baseline、随机切分时间数据、测试集调参、结果未复现、图表与正文数字不一致、因果过度声明、参考文献不可追溯。

最终结论必须标明 evidence boundary。
## v2.4 双轨终审，科学问题优先

**Scientific Reviewer** 先核查：是否回答官方目标；单位、边界、公式和代码是否一致；关键指标能否独立复算；预测是否泄漏；优化是否可行、是否真的最优；统计/因果识别是否成立；扰动实验是否证实所声称的稳定性；结论是否超过证据。任一关键失败均为 `blocking`，不得拿外观质量抵扣。

**Editorial Reviewer** 在上面完成后核查：全文主线是否由题目驱动、子问依赖是否清楚、方法选择理由是否接得上证据、图表是否回答问题、摘要与结论是否对应结果、讨论有无矛盾/冗余及引用是否真实。

参考 [通用正确性审核](solution-validity.md) 与 [论文逻辑审查](paper-argumentation.md)。两项都通过才考虑交付；“已填写 `passed`”不等于实际复核成功。
