# 竞赛论文论证结构：从题意到可信结论

优秀论文主要用于**学习叙事结构和推理逻辑**：问题如何拆解、概念如何定义、模型为何合理、结果如何支撑结论、局限如何诚实表达。**不把往届论文里的模型、问题数量、标题顺序或所谓获奖风格当成新赛题标准答案。**

## 先形成研究故事线，再安排章节

针对每一问完成六联表：

| 位置 | 必须解释的逻辑 | 最低证据 |
|---|---|---|
| 目标 | 题目究竟问什么；要输出什么 | 官方原题的可核对映射 |
| 障碍 | 为什么直接求解困难；数据有什么局限 | 数据概况、约束、现象或理论 |
| 选择 | 为什么用此建模思路，而非更简单的替代 | 方法适用假设、基准/比较、成本 |
| 验算 | 数学表达、实现和求解是否正确 | 变量/单位、边界、独立复核、必要的算法细节 |
| 证据 | 正式结果与关键指标是什么，误差如何 | 已验收实验、表/图、稳定性、反例 |
| 结论 | 这些证据支持多强的判断 | 结论范围、不确定性、局限、对题目的答案 |

先确定贯穿全文的 **problem → answer** 链，再决定按子问题、按共享模型，还是按“数据—方法—验证—应用”来组织；跨问共享的内容只讲一次，不强制“问题一/二/三”完全重复的段落和图。

## 论文可以采用的三种结构

**逐问题回答型**：问题相互独立或结果递进；每个问题内部完成“定义—方法—验证—答案”，共享数据/术语集中说明。

**共享框架型**：所有问题复用同一主模型，先写数据与统一理论，再写各问题特有的目标、修改与验证。避免同一个模型原理复制三次。

**研究链型**：如先统计分析、再预测、后优化或干预，突出子问题之间输入输出关系；给出因果/逻辑依赖图，明确误差如何向后传递。

这些都是**可选**结构而非固定模板，最终遵从当届官方要求。

## 每类段落如何书写

- **摘要**：简洁表达任务、核心思路、**已验证**关键结果、适用边界。不能只堆算法缩写；没有真实结果时不编数字。
- **问题分析**：用少量语句说明难点、决策变量、数据边界和为何采用相关方法。
- **方法**：定义符号与单位、关键假设、最必要的方程/算法，解释为什么适合该题，不粘贴大量库调用。
- **结果**：先给最重要的实际回答，再呈现支撑结果的图或表；文字应分析“多大、为何、与谁比、在哪些情形失效”，而不是复述图片。
- **实验验证**：说明切分/评估协议、合理基线、独立计算复核、消融/敏感性/稳定性，呈现失败案例与真实局限。
- **讨论与结论**：回答赛题要求，区分实证观察、模型条件性推论、假说与不可判断事项。

**一段一主张**：结论句 → 证据（图/表/公式/结果）→ 为什么成立 → 范围与局限 → 过渡到下一问。不要先写华丽结论再倒填图表。

## 双向“逻辑链”检查

- **从前往后**：官方子问 → 模型定义 → 算法求解 → 可靠性验算 → 图表/数值 → 结论。每一步都能指出引用位置。
- **从后往前**：正文每个强结论 → 具体图表 → 接受的结果产物 → 真实运行与验证协议 → 原问题。断了一环就降格为解释或待验证假设。
- **逻辑红旗**：推导过程漏条件、符号跳变、先说因果后做相关、只展示最优单次成绩、敏感性图不支持“稳健”、优化约束未验、摘要和正文数值不一致、流程图与实际代码流程不同。

## 如何从优秀论文学习，而不虚构已阅读

读取 PDF 之后，使用 [写作逻辑复盘卡](../templates/award-paper-writing-review.md) 记录 **paper_id、PDF 页码、章节序列、每章服务的研究任务、重要论证过渡、图表承担的证据功能、论证短板及可迁移的写作原则**。方法名称和高分不是复盘主角；未阅读的论文保留未审核状态。

优秀论文可能有叙述弱点：获奖本身不构成某种公式、论断、图表或段落的科学正确性证明。可以学习其叙事手段，同时独立质疑证据充分性。不能从已有 16 个 PDF 的**文件名/大小**假定已归纳其写作结构，更不能声称分析过“40 篇论文”而无可核查页码。

## 定稿审稿模式

安排两次独立复核：

1. **Scientific reviewer**：挑战假设、计算、验证、可靠性、稳定性、过强结论；任何关键失败优先修复。
2. **Editorial reviewer**：评估结构是否围绕问题、段落论证是否清楚、摘要是否与正文一致、表图是否有作用、局限是否清楚。不能用改写掩盖 scientific reviewer 提出的失败。

参见 [通用求解正确性审查](solution-validity.md) 和 [可变结构论文模板](../templates/paper_outline.md)。

## v2.5 论文数值应回指原始结果文件

论文摘要、各问结果、图表和结论必须能映射到真正保存的 `metrics_artifact`，并用 [强制回读指标与不变式审核](result-falsification.md) 检查。有数值差异时先解决结果来源与公式问题，不能仅修改论文两处数字让它们自洽。指标文件本身的计算正确性仍要用独立程序或审阅重算。

## v2.6 验证论据应在结论之前

学习优秀论文如何表达“题意→模型动机→可靠求解→结果→讨论”，但正式论文中的关键数字应有实际原始标签重算或独立数值核验支撑。参阅 [独立参考重算协议](independent-recomputation.md)：有限样例对照只支持相应数学/数据情境，不应夸大为普遍最优、泛化或因果结论。


## v2.7 将科学验证的证据嵌入研究叙事

统计显著性、仿真区间、时序误差和解析最优性只能在明确其前提后支持有限的结论。若使用 [扩展复算](extended-oracles.md)，论文应说明公式/假设、原子数据来源、独立重算结果、检验的有效范围及失败情况；不以“p 值小”“CI 窄”“求解器 success”这些标签替代完整论证。

## v2.8 从正确的求解证据到正确的论文论证

使用 [全项目证据链](project-evidence-chain.md) 追踪全部官方子问的核心结论；严格比对来自真实原子数据的独立复算、事先指定的扰动锚点和论文原始指标文件。论文的段落/章节仍按实际问题组织：题意、模型依据、可信求解、验证结果与不确定性、结论边界。只做文字润色不可能修复数值错配或漏答问题。

## v2.9 不要把高约束的数字校验当成写作结构

未知赛题可能有综合讨论、质性解释或数学证明，其结论证据不能简化为 MAE、macro-F1 或小型整数规划。学习优秀论文时应重点观察“为什么该章必须存在、为什么该段的证据支持此结论、如何从子问题衔接下一问题”。参照 [通用比赛收尾与审稿流程](competition-final-runbook.md) 用真实子问组织文章并进行独立科学/编辑双轨审核，而不是强制复用某年获奖论文的题目数和模型名称。


## v2.11 优秀论文：阅读证据与语言迁移严格分离

从仓库目录清点到 16 份 MathorCup 大数据获奖 PDF，只能说明资产元数据存在，不是“逐篇分析完成”。对于确实打开正文的每篇论文，按照 [award-paper-writing-review](../templates/award-paper-writing-review.md) 保存 `paper_id/pdf_sha256/页码/研究目标/方法动机/关键公式功能/图表作用/有效论证转折/可借鉴与不可照搬`。缺少 PDF 内容访问时标记 `unreviewed_access_blocked` 并说明阻断；禁止把未经阅读的想象当作论文风格规定。

论证修订以当前赛题为主，不直接复制获奖论文的固定章节安排。所有正文稿追加逐段语言审核：判断句式是否准确、有无“结果显著优秀”却没有外部验证、有无把条件模拟当实际数据、图题是否体现科学问题。科学与 Editorial 两次审稿都在真正的当前 PDF 页面进行，不只审 Markdown。

 
## v2.12 由存量PDF机器结构到审读论证，不能跨级
真实16篇PDF的716页机器可读取布局和48个样本页视觉复核已完成，参见 [award-paper-empirical-layout.md](award-paper-empirical-layout.md)。仅可据此描述已见的章节标签、样本图表/段落外观、候选字号差异。关于模型“为什么正确”、摘要说服力、段落推理链仍没有16篇全文人工阅读的证据，不能由字体统计或PDF存在推理得到。续接时应优先为每篇填满引用 PDF 页码的研究论证复盘卡，且一次只采纳当前赛题真正需要的写作规律。

 
## v2.13 从实际原文抽取研究论证，而不只比较排版

阅读 [16篇PDF重点章节复盘](award-paper-deep-argumentation-16.md)，分别认识：台风时空观测统一后的多问预测链、仓储预测误差对优化模型的依赖、视觉任务先审标注再按类别分析错误、物流风险弱标签的生成边界。每一条迁移建议均有原始PDF的真实物理页码；注意**已经阅读的是指定关键章节，不是716页逐字通读**。

尤其不要把优秀论文中“漂亮的实验表”“深度学习大模型”“R²=1”“迭代收敛”“QQ图近似直线”等句式不经审查移植到新赛题。2024-04第19页表7的MSE/RMSE在相同原子误差假设下有数值冲突；2024-07第19页的随机K折用于时间序列时需查证时点；2025-05第11页自制风险标签不是外部真值。以上或属事实反证，或属**明确注明的风险待核**，不可混淆。正文必须回答“为什么用模型、哪些数据可用、依据哪项合法验证、失败在哪里、结论到什么边界”。
