# Figure Evidence

每张正式图必须可追溯到真实数据或真实模型结果。

记录：
figure_id
source_data
script
analysis_question
finding
paper_location

## Preferred figure classes

- distributions
- relationships
- temporal trends
- spatial patterns
- model comparison
- ablation
- sensitivity
- error diagnostics
- prediction versus observation
- feature or variable interpretation

图表不要使用装饰性 3D、过度渐变、伪造平滑趋势或视觉重复。若离散数据没有连续观测，不得仅为好看而插值制造新结构。
