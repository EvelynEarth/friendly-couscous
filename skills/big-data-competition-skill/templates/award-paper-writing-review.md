# 优秀论文“结构与逻辑”复盘卡

**严格前提**：必须取得并实际阅读论文 PDF 正文，填入真实页面。文件存在 ≠ 已阅论文。记录此卡不等于验证了该论文的数学模型或实验结论，且不因论文获奖而免审。

| 审阅维度 | 必填内容 | 原 PDF 页码 | 本届能否迁移 |
|---|---|---|---|
| paper_id / 阅读状态 | 例如 2025-01 / reviewed 或 unreviewed | 来源路径 | — |
| 全文主线 | 题目如何拆解为研究问题；子任务是否相互依赖 | p.__ | 结构借鉴，不复制题意 |
| 摘要 | 如何交代问题、方法、最关键结果与结论边界 | p.__ | 检验是否数字真实、顺序清晰 |
| 章节设计 | 实际的标题顺序及每章为何放在此处 | p.__ | 允许改写结构 |
| 主要模型的动机 | 作者先讨论哪个困难、再引入哪个模型 | p.__ | 仅学习论证手法 |
| 方法→证据衔接 | 如何从公式/算法过渡到验证与结果 | p.__ | 对照真实结果 |
| 图表作用 | 每幅关键图支持哪个结论，还是只有装饰 | p.__ | 学论证作用，不复制图片 |
| 结论力度 | 数据能否支持强结论，有无过度推广 | p.__ | 必须独立判断 |
| 误差与局限 | 是否交代失败案例、稳定性、适用边界 | p.__ | 优先强化有缺陷环节 |
| 可迁移写作原则 | 一条具体的“什么时候这么写、为什么” | p.__ | 迁移写法，不迁移模型 |
| 论文的不足 | 对独立审稿人的潜在疑点 | p.__ | 避免重复错误 |

## 句段功能标注法

将选中的小段定位为：`problem framing`（指出目标）、`motivation`（解释困难）、`method justification`（为何选方法）、`method detail`（怎样求解）、`verification`（如何独立检查）、`evidence`（呈现数值）、`interpretation`（解释证据）、`qualification`（限制结论）、`transition`（衔接下一问）。

分析两类常见问题：逻辑跳跃（为什么突然使用这个模型？）；证据缺口（为什么这张图就能推出那条结论？）。允许指出获奖论文中的论证漏洞，不用复制它的章节标题。

## 汇总表只允许有出处的观察

一份写作原则至少引用实际审阅过的论文页码和段落功能，标记“观察/研究者推断”。没有 PDF 页码的内容只记 `hypothesis`，不当作从优秀论文中归纳的事实。纸面结构可以学习，但所有正式赛题数字、结论和图表都需重新生成。
