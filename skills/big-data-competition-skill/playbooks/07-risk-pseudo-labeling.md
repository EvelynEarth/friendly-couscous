# 07 风险 / 伪标签标注

> 适用：企业**没有历史标签**，需要先根据业务规则/数据分布造标签（如 2025 B 三类风险）。造出的标签是“伪真值”，质量决定后续监督模型上限。

## 1. 先读业务规则与硬约束

以 2025 B 为例：三类“合理诉求/诉求偏高/严重超额”；边界随实际赔付金额**动态非线性变化**；有全局比例先验（合理 ≥85%、严重超额 <3%）；同类样本索赔差额应接近、合理类密集、超额类稀疏；规则需**可解释**。

## 2. 路线 A：分位数 + 规则（透明、先做）

```python
# 按实际赔付金额分层（分位数/金额层），每层按索赔差额统计设阈值
q = df["amount"].quantile([.25,.5,.75]).values
# 每层内用差额分位数/均值+k*标准差定上下界，边界随金额变化
# 再用全局比例(85%/3%)校准阈值，满足业务先验
```
优点：完全可解释、易复现；缺点：难表达复杂非线性边界。

## 3. 路线 B：密度/异常检测 + 边界学习

```python
from sklearn.ensemble import IsolationForest
from sklearn.svm import OneClassSVM
# 1) IsolationForest 利用密度差异识别密集“合理”核心与异常点
iso = IsolationForest(contamination=.03, random_state=42)
# 2) OneClassSVM 在(赔付金额, 索赔差额)空间学习包围核心的非线性边界
oc = OneClassSVM(kernel="rbf", gamma="scale", nu=.03)
# 边界本身即可解释的动态划分函数；边界外按风险分数 + 比例约束细分
```
2025 B 获奖采用“孤立森林 + 单类 SVM”混合（IsolationForest 23、OneClassSVM 24 次出现）。

## 4. 路线 C：单调分位边界学习（MQBL）

```python
# 满足 85%/3% 先验后固化为规则
```

## 5. 标注后校验（必做）

- **比例校验**：各类占比是否满足业务先验（85%/3%）。
- **可分性**：同类差额接近、类间有明显密度差（可视化二维散点 + 边界）。
- **稳定性**：换种子/参数，标注结果一致；边界对样本扰动不敏感。
- **可解释**：能逐条说明“为什么这样划”，不使用不可解释黑盒作为最终规则。
