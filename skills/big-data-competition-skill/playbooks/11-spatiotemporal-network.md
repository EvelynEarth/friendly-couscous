# 11 时空数据、轨迹与图网络

适用：台风/交通轨迹、站点网络、城市流、路径规划或跨节点时序预测。任务类型要依据当届题面而非 2024 案例固定。

## 时空预测

1. 明确时间分辨率、经纬度坐标系、空间单位、缺失和采样偏差。
2. 按事件/时间组划分 train/val/test；同一台风事件的相近片段不应横跨评估两边造成近重复泄漏。
3. 建立 `last value` / persistence、历史平均、简单线性模型等 Baseline。
4. 视样本量选择 ARIMA/ETS、LightGBM 滞后特征、状态空间、RNN/Transformer、图时空模型等；复杂模型须有可验证优势。
5. 轨迹误差使用正确的空间度量，如球面距离（经纬度先转弧度），同时报告时间步长与终点偏差。

```python
from math import asin, cos, radians, sin, sqrt

def haversine_km(lat1, lon1, lat2, lon2):
    a, b, c, d = map(radians, (lat1, lon1, lat2, lon2))
    z = sin((c-a)/2)**2 + cos(a)*cos(c)*sin((d-b)/2)**2
    return 2 * 6371.0088 * asin(min(1.0, sqrt(z)))
```

## 图网络

- 明确有向/无向、边权、动态网络、节点 ID 与时间可见性；先运行连通性、孤立点、重复边检测。
- 先用 NetworkX / 简单图特征 / 最短路作可解释基线，再尝试 GNN；注意 inductive vs transductive 假设。
- 预测任务按边/节点/时间进行适当隔离；负采样不能泄露验证边。
- 路径、网络流或选址模型需输出**可行路径/决策**和约束违反检查，而非仅展示最优目标值。

## 论文证据

至少给出：定义与单位、切分图/表、基线与主模型对比、地图或轨迹可追踪绘图代码、误差分解/失败情况及物理可解释性。不得把坐标度直接当公里。
