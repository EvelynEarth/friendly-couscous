# Big Data Competition Skill v2.1.0

一个面向未知赛题、论文为最终核心成果的大数据挑战赛 Skill。

它吸收成熟 Data Science Agent 体系中的 EDA、Problem Framing、Baseline、Leakage Adversary、Evaluation Reality Check、Experiment Provenance 和 Evidence Storytelling 能力，同时保留本仓库在数据治理、结果验收、图表证据和论文审查方面的工程经验。

本 Skill 不采用 Kaggle leaderboard 或 platform submission 工作流。

核心链路：

赛题审计 → 数据审计 → EDA → 任务定义 → 方法选择 → Baseline → 模型与分析 → 验证 → 消融与稳健性 → 结果分析 → 图表 → 论文 → 终审 → Paper Delivery。
