# 2023 MathorCup B 题：v4→v5 章节标题数字纠错

- 用户反馈：v4 一级标题仍被 XeLaTeX 自动排为阿拉伯数字，不符合当前要求的中文大标题。
- 根因：v4 的 `ctexset.section` 只有黑体/字号/间距，没有显式声明 `name`/`number`，通用 XeLaTeX 模板也有相同遗漏。
- 修正：默认示范一级「一、二、」，二级「（一）（二）」，三级「1．」；明确标为**当前用户选择的可改风格**，不是 2023 官方强制参数。
- 本地真实编译：XeLaTeX 连续两次成功，13页 A4 PDF；机器提取目录和正文 7 个一级中文标题，逐页生成 PNG，确认未影响已知图表数据。
- 数值影响：仅更改 LaTeX 排版。v4 中原子证据、绘图、脚本与检验材料共29个文件已经与原始压缩包逐字节核对一致，没有重新生成正式预测结果。
- 门禁：`latex_paper_audit.py --heading-style chinese-tiered` 为用户要求中文编号时**按需启用**；默认关闭，未知比赛服从当届官方排版规则。
- 停点：这项整改不等于该论文全文科学复核更新、用户正式最终批准、Windows 11 本机成功编译或赛事提交。
