**变量、参数与模型**

- `z_f(t)`：浮子相对静平衡位置的垂荡位移，m。
- `z_o(t)`：振子相对静平衡位置的垂荡位移，m。
- `v_r = ż_f-ż_o`：浮子相对振子的速度。
- 浮子静水恢复刚度：`K_h = ρ g πR^2`。

常量阻尼与非线性阻尼共用动力学骨架：

```text
(m_f+m_a) z̈_f = f cos(ωt) - b ż_f - K_h z_f - k(z_f-z_o) - F_d
m_o z̈_o       = k(z_f-z_o) + F_d
```

其中：

```text
Case 1: F_d = c v_r,                  c = 10000 N·s/m
Case 2: c(v_r)=a|v_r|^n,
        F_d = a|v_r|^n v_r,           a = 10000, n = 0.5
```

这里采用 `F_d=a|v_r|^n v_r`，因为题面说的是“阻尼系数”与相对速度绝对值的幂成正比，而阻尼力仍等于阻尼系数乘相对速度。

**PTO 瞬时与平均功率**

直线阻尼：

```text
F_d = c v_r
P(t)=F_d v_r = c v_r^2
P̄(c)=稳态时间平均[c v_r^2]
```

幂律阻尼：

```text
F_d = a|v_r|^n v_r
P(t)=F_d v_r = a|v_r|^(n+2)
P̄(a,n)=稳态时间平均[a|v_r|^(n+2)]
```

由于 `n` 可变，比例系数 `a` 的量纲随 `n` 改变；论文和工作簿不把所有 `a` 统一标成 `N·s/m`。

### 两条模型路线比较

**路线 A：统一时域 ODE + 数值优化**

- 直线阻尼和幂律阻尼都直接用 DOP853 积分，外层使用有界数值优化。
- 优点：实现统一、物理语义直观。
- 缺点：直线阻尼本质为线性简谐稳态系统，若仍用黑箱搜索会浪费可解析结构，也削弱最优性证据。

**路线 B：结构化简的混合精确路线（推荐）**

- 直线阻尼：在周期稳态下转到频域，推导平均功率关于 `c` 的显式函数，并给出区间内解析最优 `c*`；再用时域 ODE 独立核验。
- 幂律阻尼：保留原始非线性阻尼力，直接以时域周期稳态平均功率为目标，使用二维有界全局优化；等效线性化/谐波平衡只允许作为解释或初值参考，不作为正式目标值。
- 优点：先利用线性部分的严格结构，再把数值优化集中在真正非线性的 `(a,n)`；同时保留可复核的边界等价关系 `n=0 ⇒ F_d=a v_r`。
- 局限：非线性部分的全局最优属于高质量数值搜索结论，不宣称数学证明的全局最优。

推荐路线：**B**。

### 直线阻尼的解析降维

设

```text
M = m_f + m_a
H = K_h - Mω^2
B = bω
G = m_oω^2 - k
```

以复幅值表示相对位移 `R=Z_f-Z_o`，可得

```text
R = F m_oω^2 / D̃(c)
D̃(c) = (H+iB)(G-i cω) + m_oω^2(k+i cω)
```

写成

```text
D̃(c) = (A0+A1 c) + i(B0+B1 c)
A0 = HG + m_oω^2 k
B0 = BG
A1 = Bω
B1 = ω(m_oω^2-H)
```

于是

```text
|D̃(c)|^2 = αc^2 + βc + γ
α = A1^2 + B1^2
β = 2(A0A1 + B0B1)
γ = A0^2 + B0^2
```

相对速度幅值为 `ω|R|`，所以

```text
P̄_lin(c)
= 1/2 · c · ω^2 · F^2 · (m_oω^2)^2
  / (αc^2 + βc + γ)
```

对 `c>0` 求导后分子正比于 `γ-αc^2`，因此无约束驻点

```text
c0 = sqrt(γ/α)
```

题面有界最优解为

```text
c* = clip(c0, 0, 100000)
```

并直接代回得到 `P̄_lin,max`。该结论是直线阻尼子问题在当前线性微幅波模型下的区间全局最优。

### 幂律阻尼的数值优化口径

- 决策变量缩放为 `u=a/100000∈[0,1]` 与 `n∈[0,1]`，避免量纲尺度差导致搜索退化。
- 每个候选点使用 Q2 原始非线性 ODE；搜索阶段固定积分 `60T`，前 `50T` 仅用于衰减瞬态，目标取最后 `10T` 的平均 PTO 功率。
- 全局搜索采用固定随机种子的 `scipy.optimize.differential_evolution`；随后在最优邻域做有界局部精修。
- 最终候选重新积分至少 `100T`，比较 `80--90T` 与 `90--100T` 两个完整 10 周期窗口的平均功率和同相位状态；若未达到稳态一致性阈值则继续延长，不允许直接报告未收敛目标。
- 最终候选再用更细 `max_step` 复算，并检查参数边界邻域，防止把数值噪声当作最优。
